How it works

One click from a moderator → a model that knows your house rules

1

Chat arrives

Every message is judged by one frozen moderation task: same model, prompt and JSON schema, so it is one task in Mubit.

allow · hold · remove · redact
→
2

Routed through Mubit

The call goes to api.mubit.ai. Mubit records it and groups it into the task it will train on.

every LLM call via Mubit
→
3

A mod corrects it

Hover a chat line, pick the right action, edit the rule. Most chat never needs this: Quell settles ~86% on its own.

“no selling in #general”
→
4

Rule + replay

The rule applies instantly. Similar messages (found with embeddings) are re-judged as recorded calls: corrected training examples.

4 corrections → 32 examples
→
5

Your own model

Mubit trains an open Qwen3 adapter on those examples, tests it, runs it on silent copies, then lets it serve live chat.

cheaper · faster · yours
Next look-alike message comes out right: 4 / 4 in testing
Benchmark: 114 held-out messages, never trained on 83% → 90% agreement after corrections Untrained open Qwen3: 79%, misses 6 of 14 scams
